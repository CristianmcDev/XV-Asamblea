# XV Asamblea Internacional – Córdoba 2024

Web desarrollada para la **XV Asamblea Internacional de Laringectomizados**, celebrada en Córdoba en 2024.

Proyecto realizado con un enfoque en **componentización, navegación SPA y diseño responsive**, utilizando React y un conjunto de librerías para gestionar la interfaz, formularios y animaciones.

## 🚀 Tecnologías

* ⚛️ **React 18**
* ⚡ **Vite**
* 🧭 **React Router**
* 🎨 **Material UI (MUI)**
* 💅 **Emotion**
* ✉️ **EmailJS**
* ✨ **Animate.css**
* 🔍 **ESLint**

## 🧩 Características técnicas

* Componentes reutilizables para estructurar la interfaz.
* Navegación mediante **React Router**.
* Formularios de inscripción y contacto.
* Integración con **EmailJS** para el envío de formularios.
* Diseño **responsive** para diferentes dispositivos.
* Organización del proyecto separando páginas, componentes, datos y rutas.
* Animaciones y elementos visuales para mejorar la experiencia de usuario.

## 📁 Estructura

```text
src/
├── Components/    # Componentes reutilizables
├── Pages/         # Páginas de la aplicación
├── assets/        # Recursos e imágenes
├── data/          # Datos iniciales
├── hooks/         # Hooks personalizados
├── router/        # Configuración de rutas
├── main.jsx
└── styles.css
```

## 🛠️ Instalación

```bash
npm install
npm run dev
```

Para generar la versión de producción:

```bash
npm run build
```
